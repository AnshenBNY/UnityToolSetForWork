# UnityToolSetForWork

面向美术与特效制作的 Unity 编辑器工具。当前验证版本：Unity 2022.3.30f1c1。

入口：**BjTools → 多功能电饭煲**，窗口标签同名。

## 使用流程

1. 在左侧选择“复制与迁移 / 检查与修复 / 批量编辑”下的工具。
2. 预制体复制页添加一个或多个预制体，点击“复制预制体…”或“复制 N 个预制体…”，查看分类清单。其他工具使用各自的“预览”按钮。
3. 预制体复制页点击“开始复制”；其他工具点击“执行预览中的更改”。执行按步骤分帧推进，可在步骤之间取消。
4. 复制页默认显示输出位置、分类数量和副本名称。“查看文件明细”支持筛选、分页及查看完整路径；共享资源与“操作记录”默认折叠。其他工具仍在下方查看结果。

预览后源文件、目标文件或相关 .meta 发生变化时，需要重新预览。工具会报告异常和 Unity 执行错误；失败或取消会恢复本次已记录的修改。

## 各工具的改动

| 工具 | 行为 |
| --- | --- |
| 预制体复制 | 支持批量添加多个预制体，合并依赖并去重复制，统一保留源文件中的子资源 fileID。支持粒子全部 Mesh 槽与权重、Shape 网格、蒙皮网格、UI 贴图、材质、动画、Timeline、音频以及模型导入器的外部引用。 |
| 贴图迁移 | 预先保留所有目标路径，区分不同来源的同名贴图；先复制并导入，再更新材质。无须修改的材质不会计为失败。 |
| 依赖记录检查 | 候选限制相同扩展名；移动过的根资源按 GUID 解析当前位置；复用依赖与名称搜索结果。外部 JSON 和 TextAsset 的选择不再互相遮挡。 |
| 非法引用查询 | 选择单个文件时以其所在目录为归属范围；源扫描也应用排除规则；支持筛选与分页。 |
| 引用修复 | 只改 Unity 文本对象引用，校验 GUID、fileID 和资源类型。子资源存在歧义时阻止执行。清空引用写入真正的 `{fileID: 0}`。 |
| 批量重命名 | 按路径稳定排序，支持起始序号和位数；预检非法名称、重名及目标占用；资源通过临时名称分两阶段改名，保持 GUID。Hierarchy 模式过滤 Project 资源。 |
| 预制体与材质映射 | 源对象保持原样；按相对路径匹配目标；支持根节点及不同 Renderer 类型；保留预制体属性覆盖和局部变换；已有同名特效节点跳过。 |
| 模型导入设置 | 仅应用勾选的参数组；补齐来源 Avatar；校验无效误差值、自身 Avatar 引用和缺失 Avatar；备份导入器 .meta。 |

## 预制体复制与保存

从 Project 选择一个或多个预制体后点击“添加 Project 中选中的预制体”，或直接把它们拖入列表区域。列表支持移除、清空和分页；重复项自动跳过，非 .prefab 资源及场景实例会明确提示未添加。源列表按项目保存，旧版的单个源预制体设置会自动迁入列表。

多个预制体各自生成副本，无须先放到场景的空物体下再另存临时预制体。本批次共用的材质、贴图、FBX、嵌套预制体等只复制一份，多个副本继续共用这些新资源；后续修改共用资源会影响使用它的副本。选中的预制体同时作为另一个预制体的嵌套资源或变体基类时，也只生成一个对应副本，并更新这些关系。

完整复制默认写入 Prefabs、Materials、FxMaterials、Meshes、Textures、ImageText、Animations、Audio 分类目录；只创建实际使用的目录。同名文件自动添加编号，重复执行会生成新的副本。

脚本、Shader、包内资源、未支持的资源类型及排除目录中的资源保留共享引用，并在预览中列出。TMP 字体等自定义 ScriptableObject 默认属于共享资源；“完整复制”按工具支持的资源类型处理，不能理解为复制项目中的所有类型。

副本在执行完成时已保存。结果中列出每个源预制体与副本名称，可分别定位或放入场景；“定位全部副本”选中本批次的根副本，“将全部副本放入场景”创建各自独立的实例，并自动填入场景实例列表，一次 Ctrl+Z 可撤销这次批量放入。

完整复制清单按整批实际资源文件去重，一份文件显示一次，不把建目录、导入和更新引用算成不同资源。默认显示每个根副本的输出名称与分类数量；文件明细可展开，同名冲突的自动编号会单独提示。完成后分别显示预制体副本数量和已保存的资源总数。修改源列表、输出或排除目录后需重新整理清单。

整批复制作为一次文件操作备份。任何一个请求复制的根预制体无效或被排除时，整批阻止执行；中途失败或取消会恢复整批已记录的文件变化。成功后“恢复上次文件操作”经二次确认可恢复整个批次，场景实例仍需单独撤销。

展开“高级：批量处理场景实例”，从 Hierarchy 多选预制体根实例后点击“添加 Hierarchy 中选中的实例”，或拖入场景列表。Project 资源、普通物体和 Prefab 编辑模式中的对象不加入此列表。重复实例只保留一次，父实例和它内部的嵌套实例同时选中时，仅保留父实例，嵌套内容随父实例处理。

“复制材质…”“复制粒子材质…”“复制粒子网格…”“复制 Image / Text 资源…”“复制 MeshFilter 网格…”“复制动画与 Timeline…”均处理场景列表中的全部实例。每次模块操作共用一套资源副本，清单列出全部处理对象，取消在当前实例处理结束后生效。成功后一次 Ctrl+Z 可撤销整批场景引用修改（资源文件保留）；失败或取消同时恢复整批场景引用、原有预制体覆盖和新建文件。场景列表不跨窗口重开或脚本重载保存。

“保存所选副本…”批量保存本次窗口会话中由工具生成的根副本实例，单个实例显示“保存副本…”。若多个实例对应同一副本文件，会阻止保存，需只保留其中一个，避免不同修改互相覆盖。嵌套对象的覆盖保存在各自根副本中，不会递归 Apply 或解包共享子预制体，保存不会顺带保存无关的脏资源。批量保存失败会还原文件，并保留保存前尚未写入文件的场景修改。

## 恢复与限制

- 文件操作备份保存在项目的 `Library/ToolSetBackups/`，包括原内容、.meta 和新增文件记录。下方“恢复上次文件操作”恢复最近一次有文件变化的已完成操作；场景修改使用 Unity Undo。
- 点击恢复后会弹出二次确认，说明恢复范围、删除新建资源及还原原有文件的影响；选择“确认恢复”才执行，选择“取消”不作修改。
- 恢复前检查整批文件。操作之后再次被修改的文件会阻止恢复，避免覆盖后续工作。清理 Library 会删除这些本地备份。
- 不会强行修复无法判断类型或 fileID 的缺失 FBX 子资源。需要先恢复原文件，或在 Inspector 中明确指定目标；不能只替换 GUID 后宣称修复成功。
- 引用修复面向 Unity YAML 文件；二进制文件不会当作文本改写。有未保存修改的目标资产、场景或 Prefab Stage 会阻止文件替换。
- 修复依赖引用不会篡改原 JSON 记录的 GUID 基线。结果项会记录本次替换，需要重新导出依赖记录来更新基线。
- 映射遇到新增/删除节点或组件的结构覆盖时会阻止执行；请先保存为独立预制体再映射，以免丢失结构覆盖。
- 一次导入、一次高级复制模块或一次保存期间无法中断 Unity API；取消发生在步骤之间。
- 输出目录、排除目录、命名与导入参数等输入按项目保存；场景对象与上次执行计划不跨重载恢复。

## 开发与验证

普通工具面板实现 `IToolGUI` 或继承 `ToolPanel`；只有主窗口继承 EditorWindow。主窗口负责选择变化通知、滚动布局与事件释放。

共用模块：

- `ToolWorkflow.cs`：执行计划、变更检查、分帧执行、结果、备份与恢复。
- `ReferenceRepair.cs`：对象引用解析、资源类型/fileID 匹配。
- `PrefabCopyPlan.cs`：批量源列表、合并依赖复制、场景实例化及高级分步适配。
- `SceneCopyPlan.cs`：场景多选、嵌套去重、批量模块复制/保存、场景快照与 Undo。
- `CopyOverview.cs`：根副本列表、资源分类摘要、文件明细、共享资源和折叠的操作记录。
- `ToolAssetCache.cs`：项目变化时失效的搜索/依赖缓存。
- `ToolPreferences.cs`：按项目保存输入。
- `ToolUi.cs`：共用界面与分页。

在 PowerShell 中运行 `Tests~/Run.ps1`，可通过 `-UnityEditor` 和 `-Dotnet` 指定安装路径。脚本在 TEMP 下创建独立工程，不会启动当前工作工程；它输出进程 ID、日志与结果路径。需要当前工程已有 Unity.Timeline / UnityEngine.UI 编译程序集，并保留多 Mesh 测试夹具 `fish_200004005_skin.fbx`。

`Tests~` 不参与 Unity 常规资源导入。回归包含批量根预制体及变体/嵌套关系、共用资源去重、资源同名冲突、真实 FBX 多 Mesh/权重、引用与子资源匹配、模型导入器引用、保存范围、批量场景 Undo、整批失败/取消恢复、列表偏好保存及清单失效检查。验证结果见 [Tests~/Validation.md](Tests~/Validation.md)。

界面目前通过源码与编译检查，尚未进行 Unity 窗口的人工视觉验收；未做大型项目的性能基准测试。
