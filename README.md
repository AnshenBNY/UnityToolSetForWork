## 1. 预制体复制

### 用途

复制预制体并按模块迁移关联资源，适合特效/UI 资源搬运与重组。

### 支持内容

- 复制预制体本体与子预制体
- 复制普通材质（MeshRenderer / SkinnedMeshRenderer）
- 复制粒子材质（含 ParticleSystemRenderer、TrailRenderer）
- 复制粒子网格、MeshFilter 网格
- 复制 Timeline / AnimatorController / 动画片段相关资源
- 复制 UI Image/Text 相关资源（材质、Sprite、字体等）
- 复制材质贴图并回写材质引用
- 支持排除目录

### 基础配置

- `当前处理预制体`：可拖入 Project 中的预制体资源，也可拖场景实例（分步模式）
- `输出文件夹`：必须指定
- 可选：开启详细日志、步骤耗时统计、延迟资产操作优化
- 可配置多个排除目录（目录内资源不复制）

### 一键模式

- `一键复制所有`
- `一键复制并保存`

一键模式会按固定顺序执行全流程，并在输出目录自动创建子目录：

`Prefabs / Materials / FxMaterials / Meshes / ImageText / Textures / Animations`

> 注意：一键模式要求“当前处理预制体”为 Assets 内的预制体资源，不支持场景实例。

### 分步模式（常用顺序）

1. `复制预制体`（仅支持 Assets 预制体）
2. 将复制出的预制体放到场景中
3. `复制材质`
4. `复制粒子材质`
5. `复制粒子网格`
6. `复制Image/Text资源`
7. `复制材质贴图`
8. `复制 MeshFilter 网格`
9. `复制动画 Timeline`
10. `保存当前处理预制体`

### 使用建议

- 角色/模型类：重点用“复制材质”
- UI 类：重点用“复制Image/Text资源”
- 特效类：重点用“复制粒子材质 + 粒子网格”

## 2. 依赖记录检查

### 用途

将源工程资源依赖导出为 JSON，再在目标工程解析，快速定位丢失依赖与目录变化，并支持候选修复与报告导出。

### 推荐流程

1. 在 `1) 目标选择` 中添加目录/资源（支持拖拽与“添加当前Selection”）
2. 在 `2) 导出配置与保存` 里设置规则后导出 JSON
3. 在目标工程中载入 JSON 并 `解析并检查依赖`
4. 对丢失项搜索候选并按需修复

### 导出配置说明

- `包含 Unity 内建依赖`：通常不建议勾选
- `排除 Editor 目录资源`
- `排除扩展名`（逗号分隔）
- `JSON 文件名前缀`
- `排除目录规则`
- `JSON输出目录` 可浏览/恢复默认
- 导出按钮：
  - `保存到输出目录(JSON)`
  - `另存为(JSON)...`

### 解析检查说明

- 可通过 `记录文件(TextAsset)` 或 `选择JSON文件` 指定记录
- 点击 `解析并检查依赖`
- 结果统计包含：总依赖 / 存在 / 丢失 / 内建
- 可选：
  - `仅显示丢失项`
  - `候选显示上限`
  - `修复仅限 JSON 记录范围（推荐）`
  - `修复时扩展扫描根对象依赖链`

### 丢失项处理

- `为丢失项搜索候选资源`
- `导出丢失报告(CSV)`
- `导出丢失报告(JSON)`
- 在卡片内可：
  - 查看引用来源并 `跳转`
  - 对候选资源 `Ping`
  - `使用该候补修复`

## 3. 非法引用查询

### 用途

扫描指定对象中的“越界依赖引用”（引用到不应依赖的外部资源），并提供定位与修复动作。

### 操作步骤

1. 在 `查询对象` 添加要扫描的目录/文件（支持拖拽与 Selection）
2. 在 `忽略规则` 配置：
   - 是否排除 `Editor` 目录
   - 排除扩展名（如 `.cs,.dll,.asmdef`）
   - 排除目录列表
3. 点击 `开始查询`
4. 在结果卡片中处理每条非法引用

### 支持处理动作

- `查找候选替换`
- `删除引用(GUID置空)`（直接移除引用）
- `复制到目标目录并替换`
- 对候选执行 `替换为此资源`

## 4. 贴图复制迁移

### 用途

扫描目标材质目录引用的贴图，复制到指定输出目录，并回写材质中的贴图引用。

### 操作步骤

1. 选择 `目标材质文件夹`
2. 选择 `贴图输出文件夹`
3. 可选：添加 `排除目录`（这些目录下贴图不会复制）
4. 点击 `复制并迁移贴图`
5. 在结果区查看：
   - 已处理材质
   - 已复制贴图
   - 跳过贴图
   - 失败材质

## 5. 批量重命名

### 用途

批量修改资源文件名或 Hierarchy 节点名。

### 作用对象

- `资源文件`（Project 选中）
- `Hierarchy节点`（Hierarchy 选中，可选“包含子节点”）

### 重命名方式

- `基础名称加序号`（格式：`新基础名_序号`）
- `替换部分字符串`
- `插入字符串`（开头/结尾/指定位置）

### 操作步骤

1. 先在 Unity 中选中目标
2. 在工具里设置作用对象与命名规则
3. 点击 `重命名`
4. 在“当前选择”面板确认结果范围

## 6. 材质预制体映射

### 用途

将源根节点中的预制体映射/材质映射到目标根节点对应结构，适合同骨架或同层级对象的批量替换。

### 功能项

- `预制体映射`：按相对路径在目标节点挂载对应预制体
- `材质映射`：按相对路径把源 Renderer 材质赋值给目标

### 操作步骤

1. 指定 `源根节点` 与 `目标根节点`
2. 勾选需要执行的映射项（可同时勾选）
3. 点击 `运行`

> 注意：预制体映射会解包源根节点中的父级预制体实例。

## 7. 批量修改模型导入设置

### 用途

对当前选中的模型资源（如 FBX）批量应用导入参数。

### 配置组（可独立开关）

- `材质导入设置`：Material Import Mode
- `动画误差设置`：
  - Animation Rotation Error
  - Animation Position Error
  - Animation Scale Error
- `Avatar 设置`：Avatar Definition

### 操作步骤

1. 在 Project 视图选中一个或多个模型资源
2. 勾选需要应用的参数组并设置值
3. 点击 `应用`

## 常见问题与建议

### 1) 为什么按钮点了没有效果？

- 先检查是否已选中正确对象（Project 或 Hierarchy）
- 检查输出目录是否有效
- 查看工具底部状态提示

### 2) 一键复制报错“只能处理 Assets 中的预制体”

- 说明拖入的是场景实例，请改为 Project 内预制体资源

### 3) 如何降低误处理风险？

- 建议先在小范围资源上试运行
- 先使用“查询/导出报告”类功能确认影响范围，再执行修复
- 大批量处理前建议先提交版本控制或创建备份

### 4) 处理后需要手动做什么？

- 建议检查 Console 日志与状态栏提示
- 关键资源（特效、动画、UI）请做一次场景回归验证
